# 发布前检查与交接

先写清楚当前状态：**草稿待确认**、**待补资料**或**用户已确认，交用户发布**。后者只能用于用户明确确认了当前文案与素材安排，且发布所需问题已解决时；有未解决项就列为阻碍，不保证可以发布。

## 检查

- 名称、规格、价格、日期、活动条件、案例与数据是否逐项有用户资料依据？
- 是否遵守品牌边界，删除了无法证实的绝对化承诺？
- 文案是否符合用户给定的平台、受众、篇幅和语气要求？未知的平台限制不能自称已检查。
- 图片、引文和人物素材的使用范围是否已由用户确认？不能替用户确认版权。
- 用户提供的链接与联系方式是否准确抄录？未访问的链接不声称可用。
- 本轮完整稿件、配图及修改是否已获得用户确认？旧版同意不自动覆盖新版。

## 交接格式

1. 当前状态与待解决事项。
2. 最终标题和完整正文，注明聊天中的稿件版本。
3. 配图文字建议或用户提供的素材名及放置位置；不伪造附件。
4. 平台、发布人、计划时间：由用户提供，没有则待确认，不擅自安排。
5. 发布后建议用户带回：实际发布链接或截图、发布时间、统计时间与同口径数据。

这份清单没有发布、排期、发送、提醒或保存业务记录的效果。用户自己执行发布；用户后来反馈发布结果时，仅注明“用户反馈”，不能把反馈当成系统已验证的回执。
