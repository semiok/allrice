# 内容复盘约定

只使用用户提供的数据。可请用户给：内容或稿件标记、平台、发布时间、统计截止时间、曝光或阅读、互动、点击、转化，以及这些指标的定义和来源。并非每个平台都有这些指标，按实际可用项整理。

交付四部分：

1. **数据摘要**：指标、数值、期间、来源。未知写“未知”，不要填零。
2. **观察**：发生了什么变化；只有统计窗口和指标口径可比时才作直接比较，否则说明不能直接比较。
3. **解释边界**：哪些只是猜测，哪些还缺证据。单条内容表现不能证明某个标题、发布时间或图片导致了结果。
4. **下一轮建议**：两到三条可尝试的调整，说明需要用户决定什么，以及下次需保留什么数据。

计算比率须明确分子、分母与期间；分母未知或为零则不计算。样本很少时只描述本次观察，不推出普遍规律，不承诺下一条必然增长。

没有数据时只给适用的待收集清单；只有单条数据时不给虚构基准。用户仅提供链接时不自行抓取。建议只留在聊天里，不宣称已成为系统长期经验或已安排下一次任务。
