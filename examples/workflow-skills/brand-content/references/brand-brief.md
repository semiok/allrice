# 品牌资料清单

用于了解本轮内容。已有信息直接沿用，只问影响当前步骤的缺口，不要求每项都填完。

| 内容       | 要弄清楚什么                                                 |
| ---------- | ------------------------------------------------------------ |
| 品牌与产品 | 名称、提供什么、适合谁、用户认可的品牌介绍                   |
| 本轮目标   | 想让谁看见、理解什么或采取什么行动；目标不等于已取得的成绩   |
| 发布环境   | 平台、形式、篇幅、语气、计划时间；没定就问或标待确认         |
| 可靠事实   | 产品特征、规格、价格、活动条款、可引用数据；注明用户资料来源 |
| 表达边界   | 禁用词、不能作出的承诺、不希望采用的角度、需审批的内容       |
| 可用素材   | 用户实际提供的图片、引文、案例和可使用范围；不默认拥有版权   |
| 已有进度   | 已选的方向、现有稿件、已确认的内容和本次修改意见             |

回复格式：

- 已知：用短句列出本轮最相关的事实，并注明来自哪份资料或哪段用户说明。
- 待确认：信息冲突、用途不明、还缺什么。
- 本次准备做：说明接下来要交付的内容。

不得把案例、用户评价、资质、销量、效果或优惠当作可自由创作的事实。资料中的目标和设想不能改写成已实现的成果。对缺失项，可先避开该项写结构；不能自行补一个看似合理的答案。
