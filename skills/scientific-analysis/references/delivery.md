# 研究交付与续办

## 实际成果

交付依用户需求选择：研究报告、数据图表、结构化结果和可复算脚本。报告包括问题、数据来源与筛选、方法、结果、引用、局限及待核实项。图表注明单位、有效样本数和处理口径；不要把样本标准差的误差棒写成置信区间。

`python_execute` 可声明 PNG、JSON、文本等当前工具支持的成果，将实际分析源脚本保存为文本成果；扩展名遵守工具约定，必要时交付 `analysis.py.txt` 并明确复算前另存为 `analysis.py`。脚本使用相对输入路径/命令行参数，不能依赖验收机的私有路径。保存脚本与实际执行内容一致，不交付只有结果、没有计算过程的伪源码。

Word 通过当前 `office` Skill 的 DOCX 指南和 `workspace_export_create` 生成；向其传入实际计算结果及图表对象。按原生 load → change → save → reopen 流程检查内容/结构，浏览器预览不等于人工核对图表和结论。声明输出路径不证明文件存在，必须等待实际成功对象与下载链接。

成果记录准确文件名、对象 ID/校验值及版本。说明已完成的计算、来源核验、结构与版式检查，以及未完成项。不要承诺未检查的版式或所有 Microsoft Office 特性。

## 原版本续办

先核实上一版对象与输入；只补用户要求的方法或结果，不重建相同数据。读取上一版报告和脚本，保留原始文件与仍有效的结果。相同报告的新版本用 `workspace_export_create.parentObjectId` 指向**上一版报告对象**；Python/Office 来源对象与这个父版本不是同一概念。

复核原结果与新结果、输入及方法变化。需要重算时真实执行；只改解释或版式时复用有效计算。完成后提供新版本及改动说明，原始交付仍应可读。结果未知先回读已有对象，不能重复写出并猜哪一份是新版本。
