# 从问题到可复算分析

## 核对输入与证据

- 记录研究问题、对象、采集时期、单位、文件版本/校验值和数据来源。区分真实公开数据、用户数据、合成演示及自己生成的样本；不要改变这些身份。
- 列出关键变量、缺失标记和筛选规则。每项统计保留原始行数、有效样本数及排除原因；按分析所需变量筛选，避免一律删除所有含缺失字段的行。
- 保存来源的作者/机构、标题、日期、URL/DOI和支持位置（页码、章节、表号）。区分论文、简化数据集和方法文档的各自用途；同一来源的转载不能算独立证据。
- 先读已有文件。公共链接可用实际获准的网页工具核实；不可读的材料列为待核实，不编造其内容，也不将查不到转化成无限重试。

## 计算与验证

用 `python_execute` 计算，精确传入已授权对象的 ID、校验值和相对输入路径；读取 `/tmp/work/input/<path>`，将声明成果写入 `/tmp/work/output/<path>`。默认 `location: "auto"` 沿用已有本地优先选择。只用配置中确实可用的库；缺库时使用适当的已有方法或说明限制。

统计口径必须明确：样本标准差使用 n-1；不同分组的样本数逐项报告；平均比率和汇总比率不能混用。描述性结果不自动支持总体推断。分层、配对、同一对象多次测量或同一巢/班组的数据需按设计解释；没有可识别的聚类信息时，不声称已解决依赖结构。

脚本从文件计算结果，不硬编码最终数值；固定随机分析的 seed、次数和算法，并说明敏感性。输出至少保留输入标识、筛选规则、统计量、单位和方法。核对关键汇总与预期维度，保证报告及图表用同一份结果，避免手抄数值不一致。

重跑应能复现数值；运行耗时或一次成功不能证明所有数据、学科或方法都适用。方法失败先查看工具回执，已有有效成果只补缺失检查。
