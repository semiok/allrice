# 租户设置

设置复用现有 DSH SettingsPanel 和发布包控件，按以下顺序展示五项：个人偏好、我的电脑、工作方式、已链接应用、账号与用量。打开设置默认进入个人偏好。

- 个人偏好管理字号、工作步骤、收起时机和流式输出。流式输出默认开启，保留账号已保存的关闭选择。
- 我的电脑管理 Bridge、授权文件夹和本地权限。原「能力与环境」中的五项本地状态收进「本地能力状态」，默认折叠；修改权限或电脑环境变化后重新读取实际状态。
- 工作方式管理云端自动工作、电脑自动工作和自动安排助手。「云端与助手状态」默认折叠，继续按当前员工、授权和环境展示真实就绪情况；刷新保留已有卡片与展开状态。
- 已链接应用统一管理本人应用连接，不在能力状态中重复展示连接列表。
- 账号与用量保留账号、密码、配额、存储与退出操作。

删除「我的技能」「能力与环境」独立菜单、「文件夹自动处理」链接和「业务站点」表单。旧 `settings=capabilities/experience` 链接进入工作方式，旧 `settings=skills` 进入个人偏好；不删除已安装技能、文件夹规则或既有站点授权数据。

电脑浏览器默认保留登录，仅保留「清除登录」操作。清除前在原页面内确认；确认后复用既有授权轮换和旧资料清理协议，不增加浏览器实例或模型任务。取消不写入。清除已成功而后续状态刷新失败时，保留新的授权，不能重复使用已撤销授权重试。旧临时授权在用户操作前继续按原设置工作；清除确认明确告知后续登录默认保留。
