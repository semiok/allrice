# 应用调用失败提示

收到远端错误回执与未收到完整回执使用不同的提示。已结束的失败运行显示具体原因及下一步：GitHub 合并接口的已知 403 PAT 错误提示检查仓库范围和 Contents 读写权限，普通远端错误提示核对应用结果，无回执才提示结果待核实。原有助手回复保留。

历史会话从同租户、工作区、会话及所有者的不可变 MCP 回执生成固定枚举；不改写运行、操作结果或历史消息，不把远端输出当作指令，也不自动重试。未知副作用仍按原账本记录，显示错误原因不等于证明远端回滚。

已结束且操作处于 unknown 的页面停止自动轮询，提供手动刷新；实际运行和停止中的操作继续观察。GitHub 连接说明区注明“已连接”不等于具有所有操作权限。

验证包含错误回执分类、历史访问隔离、保留输出、未知状态不重放，以及 Dev 上 Run df14b238 的实际页面。
