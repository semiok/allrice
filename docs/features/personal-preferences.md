# 个人偏好：回复输出方式

入口：聊天侧栏「设置 → 个人偏好 → 流式输出」。继续使用已接入的 DSH SettingsPanel，以及官方 primitives 包的 Switch。

- 默认关闭：任务结束后统一显示最终回复；执行期间仍显示工作状态、总耗时和需要用户处理的操作。
- 打开：实时显示文字，按原生顺序交错展示中间回复和工具步骤。切换立即影响当前页面，正文与轮次导航预览遵循同一偏好。
- 偏好保存在账号下，所有员工和工作区通用，刷新或换设备后仍有效。普通成员可修改自己的偏好，无需管理员权限。
- 保存失败时保持原值并提示重试；切换账号会隔离旧请求和旧偏好。

`0109_user_preferences.sql` 添加账号偏好表，GET/PATCH `/api/v1/me/preferences` 只使用认证身份，不接受目标用户。Workspace 初始响应携带偏好，避免加载时先展示不符合偏好的回复。关闭流式展示不停止 SSE，不改变模型调用、工具执行或事件持久化。

验证：PostgreSQL 账号隔离与持久化；接口认证、输入校验和失败响应；Chromium 默认关闭、运行中切换、保存失败、刷新恢复、账号切换及结束后的统一回复。官方组件导出由 `dsh-ui:verify` 校验。
