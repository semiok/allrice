# 个人偏好：回复输出方式

入口：聊天侧栏「设置 → 个人偏好 → 流式输出」。继续使用已接入的 DSH SettingsPanel，以及官方 primitives 包的 Switch。

- 默认开启：实时显示文字，按原生顺序交错展示中间回复和工具步骤。切换立即影响当前页面，正文与轮次导航预览遵循同一偏好。
- 关闭：任务结束后统一显示最终回复；执行期间仍显示工作状态、总耗时和需要用户处理的操作。
- 偏好保存在账号下，所有员工和工作区通用，刷新或换设备后仍有效。普通成员可修改自己的偏好，无需管理员权限。
- 保存失败时保持原值并提示重试；切换账号会隔离旧请求和旧偏好。

`0109_user_preferences.sql` 添加账号偏好表，`0209_streaming_output_default.sql` 将新记录的 SQL 默认值改为开启，不修改已有选择及其时间戳。未保存偏好的账号同样默认开启。GET/PATCH `/api/v1/me/preferences` 只使用认证身份，不接受目标用户。Workspace 初始响应携带偏好，避免加载时先展示不符合偏好的回复。关闭流式展示不停止 SSE，不改变模型调用、工具执行或事件持久化。

验证：PostgreSQL 默认开启、显式关闭保留、账号隔离与持久化；接口认证、输入校验和失败响应；Chromium 默认开启、运行中切换、保存失败、刷新恢复、账号切换及关闭后的统一回复。官方组件导出由 `dsh-ui:verify` 校验。

子智能体设置同在「设置 → 个人偏好」：最大递归深度接受非负安全整数（0 禁用，1 仅允许主员工创建），并行数量上限接受正安全整数，所有层级共用且不计主员工。留空保存为 `null`、跟随 DSH 默认深度 1 / 并行 8；填写后失焦或按回车自动保存，下一次任务生效。复用现有偏好接口，只更新 `subagents`，保留外观、阅读等其他偏好。入口不依员工是否安装 Workflow 隐藏；普通对话的正式启用由原生委派启用片负责。
