# 租户反馈与文件修改

回复完成后，鼠标移入或键盘聚焦显示官方 DSH 消息尾栏：复制、赞/踩、总用时、日期。触屏持续显示；已有评价持续可见，可撤回。沿用官方七类反馈弹窗与失败重试体验，不开放分支。评价只写数据，不调用模型或发起任务。

平台管理 → 租户反馈（`/runtime-console?view=feedback`）可按租户、员工、评价、分类和处理状态筛选，查看对应问题、原回复、员工版本和运行信息，记录「待处理 / 处理中 / 已解决」与处理备注。仅平台管理员可跨租户查看；不返回模型凭据或完整原始运行日志。

文件预览下方改为「让当前员工修改」：填写一条要求并点击「提交修改」，自动绑定当前文件版本并续接同一会话的员工。保留 Diff 选中行定位及历史修改记录；不用加入批次、保存草稿、再单独发起任务。保存回执或任务回执丢失时保留输入，重试复用反馈和消息身份，避免重复任务。过期版本继续禁止提交。

## 数据与复用

- 迁移 `0108_tenant_feedback_inbox.sql` 扩展既有 `allrice_run_feedback`，保留旧评价入口兼容。新增 UUID 版本令牌、分类和处理记录；旧 reviewed 状态迁移为 resolved。
- 租户路由 `/api/v1/sessions/:id/message-feedback` 核对当前成员、会话所有权、工作区与真实助手回复，使用版本比较处理并发和撤回后重建。
- 平台路由 `/api/v1/admin/tenant-feedback` 独立校验平台管理员；处理记录并发更新失败返回 409，不覆盖较新的反馈。
- 固定官方 WebUI `0.1.7-rc.1`，组件、样式、controller 与适配补丁登记在 `upstream.json` 的 `message-feedback` 中，`pnpm dsh-ui:verify --source <DSH checkout>` 可重放校验。

## 验证

`message-feedback.integration.test.ts` 覆盖真实 PostgreSQL 租户隔离、成员撤销、首次并发、版本冲突、删除重建、旧入口、后台筛选与处理，确认评价不增加任务。

`workbench-layout.browser.test.ts` 在 Chromium 中覆盖悬停、复制、原生反馈对话框、失败保留、撤回和后台处理；文件修改覆盖两阶段回执丢失后的相同身份重试。既有 P07 Chromium/PostgreSQL 夹具继续验证 Diff 定位、版本变更与唯一续接任务。

长会话回归同时核对轮次导航：观察器在完整消息子树挂载后绑定 DOM 引用，历史消息共用时间格式器，避免新增消息操作栏放大重复格式化开销。
