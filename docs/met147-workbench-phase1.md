# MET-147 · UX01-A：工作台可见

本 PR 只完成既有工件能力的租户呈现，不改 Agent Loop、模型预算、审批策略或执行权限。基线为 MET-150 的 `8dd0553`；Phase 2 的能力引导和 Phase 3 的真实执行验收仍独立交付。

## 交互约定

- 宽屏（> 1100px）：左侧任务历史、中间对话与决策、右侧工件与审查默认常驻。用户可以收起左右栏。尚无会话/工件时展示明确空态，不发起不存在会话的请求。
- 窄屏：右栏默认关闭，入口始终可达，点击打开模态抽屉。抽屉内约束键盘焦点，Escape 关闭并恢复触发点。已打开的工作台跨断点保留，避免丢失审查草稿。
- 手机左侧历史从图标栏展开为抽屉；选择会话后收回，不把手机临时状态写入桌面布局偏好。
- 持久化仅保存布局布尔值，按登录用户、组织和工作区隔离；不保存内容、凭证、Run ID 或审查草稿。没有可信用户身份或存储不可用时使用会话内默认值。窄屏折叠不覆盖宽屏偏好。
- 新的真实工件版本就绪时，默认展示最新版本；不抢输入焦点。用户明确选过版本/消息，或有未保存审查意见时，只提示新工件可查看。用户明确收起后不强行展开。
- 已完成且关联真实工件的回复在中栏显示摘要与工件入口，原回复仍可展开；流式内容和失败信息不折叠。普通短回复不生成工件。
- 历史长回复可只读预览，显式标记为「消息预览，非已发布工件」。不伪造版本、来源，不修改历史 Run、消息或用量账本。
- Markdown 工件复用安全渲染器（无 HTML 执行、无远程图片加载），保留分页原文及行级审查；超大正文降级分页文本。Diff 继续使用现有 Cline 适配层。
- 会话切换清理所选内容；旧请求不得覆盖当前会话。刷新失败保留已打开的审查内容并显示错误，而不是丢弃草稿。

## PR 验收边界

自动测试覆盖真实 React/Chromium 的宽/窄布局、空态、用户偏好、工件自动就绪、焦点与草稿保护、显式收起、会话切换、失败重试、历史预览和安全 Markdown。复用原有 Diff/审批/输入隔离回归。

不宣称完成真实模型研报、网页审批 → Bridge 执行、多助手或浏览器任务验收；这些留在 Phase 2/3。测试 fixture 不代表生产数据，不会重跑历史 Run `49fe3f09` 或消耗订阅额度。
