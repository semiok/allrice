# MET-151 PR-4：租户验收与交付

基于 PR-3 #80（`025056b`）的独立 PR。不合并 main，不部署 Prod。用户已授权候选版本仅在 Dev / Snow 验收、通过管理页面临时配置所需能力，结束后恢复临时配置；Snow 保持普通成员，长期用户月额度 500 万不回退。

## 管理路径

Runtime Console → 租户管理 → 租户 / 工作区 → **验收与交付** → 实际使用者。

- 展示当前策略版本、后续新 Run 的员工分配版本，以及能力的所有前置条件；可直接跳到策略、环境 / MCP、员工发布、额度页面。链接保留租户、工作区和使用者，不能把目标用户当作登录身份。
- 观察设备只用于核对实际执行设备，**不改变执行绑定**。矩阵明确按使用者全部设备汇总；实际操作绑定其他设备时提示不能算当前设备的验收证据。没有 Bridge 不等于云端也不能执行。
- 额度预检复用原账本与分层限制。未知不显示为 0，读取失败不承诺可执行。总量包含缓存，缓存只作输入子集展示；不推算 Codex 官方订阅余额，不重新引入 136k 成功警告。
- 最近 50 个实际 Run 可选，也可粘贴完整历史 Run ID。服务端校验 Run / Session / 组织 / 工作区 / 所有者。显示冻结员工版本、已有用量组件、最多最近 150 条事件投影、实际操作与审批状态。
- 操作投影最多 32 条，输出为有界前缀，不回传原始 snapshot、凭证配置或未投影事件。常见凭证形式再次遮蔽，但不是对任意用户文件中任意秘密的通用识别保证。
- 工件使用现有持久化对象、SHA-256 校验、安全 Markdown、Cline Diff、静态栅格限制；HTML/SVG 仅惰性文本。文件超过预览限制提示由本人到工作台下载，不增加管理员代审批 / 代写入 / 代执行入口。
- 无工件、无执行记录、仅回复文本、已审批但未执行、未知结果分别显示，不能把状态文案当作物理执行证明。管理员查看记录保留真实查看者，不伪造 Snow 的任务。

## 权限边界与兼容

`GET /api/v1/admin/tenants/:organizationId/validation?workspaceId=...&subjectId=...`：配置及就绪预检；附 `runId` 读取该使用者实际 Run；再附 `artifactId` 只读预览该 Run 的工件。无写方法。

复用 PR-3 的真实管理员 / 活动租户 / 使用者检查；存储读取前后重新授权。新审计事件 `tenant.run.inspected`、`tenant.artifact.access_checked` 记录真实管理员与目标用户。后者表示预览授权检查，不宣称用户已经看完文件。

旧租户工件 HTTP 复用提取的静态预览函数，原来的授权、写入及反馈权限不变。原 Runtime Console Session 时间线接口默认行为不变；本页只读取指定 Run，并限制事件量。

本 PR 不新增迁移。整组首次部署仍需 PR-3 的 `0100_tenant_scoped_resource_quotas.sql`：先停止新请求并排空旧 Web / Worker，再迁移并启动匹配代码。迁移不改已有额度值、账本或角色。兼容回退必须保留按组织读取额度的修复；不可在新覆盖配置存在时直接启动旧的无组织过滤版本，也不可自动删行以恢复旧唯一键。

已完成的代码验证与真实环境验收分开记录；隔离 fixture 不是 Snow 实测。
