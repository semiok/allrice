`GET /api/v1/admin/tenants/:organizationId/validation?workspaceId=...&subjectId=...`：配置及就绪预检；附 `runId` 读取该使用者实际 Run；再附 `artifactId` 只读预览该 Run 的工件。无写方法。

本 PR 不新增迁移。整组首次部署仍需 PR-3 的 `0100_tenant_scoped_resource_quotas.sql`：先停止新请求并排空旧 Web / Worker，再迁移并启动匹配代码。迁移不改已有额度值、账本或角色。兼容回退必须保留按组织读取额度的修复；不可在新覆盖配置存在时直接启动旧的无组织过滤版本，也不可自动删行以恢复旧唯一键。
