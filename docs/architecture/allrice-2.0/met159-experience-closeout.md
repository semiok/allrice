## 后台入口简化

- 主导航仅三个入口；默认进入 AI 员工团队。
- 连接与用量下展示应用与电脑、用量。应用状态沿用既有成员作用域连接查询，过滤已删除记录，区分准备中、需登录、已连接和已断开；电脑显示实际连接与已选文件夹。
- 用量先显示所选成员在当前工作区的实际统计，额度层级和编辑表单折叠进详情，不合计重复作用域的统计。
- 执行策略、底层连接配置、运行检查进入开发者工具。既有深链接仍可进入对应工程页面，普通流程不展示工具矩阵或要求逐工具授权。
- 继续复用已有管理 HTTP、资源归属和数据库读取；查看概览不新增授权或冒用成员身份。

## 后续自动执行设置

前台复用 DSH 原生 Settings 和 Switch，提供默认开启的云端自动工作、我的电脑自动工作、自动安排助手。前两项关闭后相应执行操作逐次确认，助手关闭后不再安排助手。Bridge 的能力开关仍只表达本机能力是否启用。

执行决策必须贯穿服务端、执行器和 Bridge：沿用员工已发布工具、本人连接和已选目录，授权范围内直接执行，超范围申请；关闭、撤回和并发修改要在实际执行前重新检查。旧审批的拒绝、撤回和过期不可因开启自动执行而被重放。

后台 PR 不提前宣称自动执行已实现。自动执行另以真实 API、数据库、执行器和普通成员工作台验证后交付，不依赖 MET-145/146。
