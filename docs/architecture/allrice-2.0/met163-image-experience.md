# MET-163 图片体验与验收

平台「模型配置」统一选择对话模型和图片开关。当前图片选项为实测支持现有 Codex 订阅的 GPT Image 2.5 Flare。员工继承平台配置，图片关闭时不向新任务开放图片工具；变更在下一 Run 生效。

图片交付在聊天正文显示固定预留空间的预览卡，使用鉴权下载接口加载，避免图片加载后挤动正文。点击进入原有成果侧栏，使用现有 DSH ZoomViewport 缩放、适应宽度和触控操作；下载、历史版本沿用现有文件机制。图片预览去掉外层 48vh 裁切，避免遮住内部 60vh 视口的底部缩放按钮。仅对成功返回的图片工具记录「云端-图片」。

平台设置中的「最近图片调用」按需展开，显示最近 50 次调用的租户、生成/编辑、状态、模型和已知 Token。无回执用量显示「待核对」，已终止或租约失效的遗留 running 调用显示「结果待核对」。明细仅平台管理员可读，不向租户返回其他租户的记录、不包含原图或提示词。不把图片回执 Token 当作官方订阅余量或图片价格。

## 验收证据

- 1440px、390px × 流式、统一输出：任务完成后图片只展示一次、工作方式持久化、刷新后仍可预览和下载。使用真实 React/DSH UI、隔离 HTTP 夹具，不冒充已部署环境。
- 平台设置浏览器：默认关闭，启用保存后刷新保留，Gemini 不在模型选项，未知记录不显示 0 Token。
- API：租户身份拒绝，管理员记录不缓存；数据库：平台管理员读取、取消任务的遗留记录显示待核对。
- 真实 Codex 订阅的生成/编辑/成果存储证据见 `met163-image-execution.md`。图片本身非前端模拟，UI 自动化使用合成图片避免消耗模型额度。
- 2026-09-27 补跑完整 `executeEmployeeRun`：自然语言要求先生成蓝圆、再改成橙圆。工作模型 `gpt-5.6-luna` 自主依次调用 `image_generate`、`image_edit`，自动传入原图 objectId/checksum；原生会话以 completed 结束，并给出两份鉴权下载链接。实际 Flare PNG 分别为 731394 / 1098056 字节、1254×1254，保留 v1/v2；两次图片回执 input/output 分别为 2350/57、4302/85。图片已人工检查且 SHA 与回执一致。验证使用隔离数据库和存储，未发布到共享 Dev。
- Worker 和 Next.js 生产构建、Web 类型检查通过；定向 UI/HTTP/数据库检查纳入 CI。
