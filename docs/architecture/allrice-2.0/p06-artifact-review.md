# P06：工件与版本反馈

MET-117 / B2 / S2 / R2，依赖 P01/P04，交付顺序遵循唯一执行总表。

复用 `allrice_storage_objects`、`allrice_deliverable_versions`、文件下载和 StoragePort。
工件 ID 就是现有交付物版本 ID；只增加来源/Run/执行目标投影和反馈表，不复制一个版本库。
旧成果以 `legacy_deliverable` 来源读取，不为历史数据猜造 Run、执行目标或已批准状态。

Changeset 是单独的 JSON 工件，精确列出路径、修改前后文本与 SHA-256、实际目标/工作副本。
它只是提案，P06 没有派发、批准或本地写入；P08 才做精确落盘及恢复。
普通正文/图片反馈与 Changeset before/after 行锚点均绑定不可变对象 checksum。
草稿采用乐观版本；提交幂等且内容冻结，新工件版本只使旧反馈过时，不把它自动标成已处理。
处理记录必须关联同一系列更晚版本和明确说明；计划认可与文件动作授权仍分离。

授权在事务中重新核对租户、当前成员、会话及拥有者；对象状态、保留期和所属人
在读取与评论前重检。Worker 发布另外核对当前 Run、冻结能力及 Job 租约；媒体内容按 hash
核实并放在 StoragePort，数据库不保存大段文件正文。文件内容不作为指令或权限来源。

## 接口与边界

- `ALLRICE_WORKBENCH_ENABLED=1` 才启用 Worker 新发布路径与浏览器 API；默认关闭。
- `/api/v1/sessions/:id/artifacts` 支持稳定游标，每页 50 条；单一版本详情、内容与反馈分别读取。
- `/artifacts/:artifactId/feedback`：PUT 存草稿，POST 提交整批评论，PATCH 关联回应版本。所有写请求检查同源、正文大小及精确版本；身份来自服务器登录，不接受调用者指定拥有者。
- 每个版本、每位用户最多 100 批反馈，每批 20 条、每条 4000 字；达到上限明确拒绝，不悄悄截断历史。
- 内联内容最多 512000 字节，读取期限 10 秒；校验实际大小及 SHA，读取后再检权限。HTML/SVG 返回 JSON 转义文本，不作为主站页面执行；其他二进制／大文件只下载。实际渲染与浏览器恶意内容用例由 P07 完成。
- Changeset 最多 32 文件、总 JSON 512000 字节。这里只记录提案，目录授权不自动变成落盘批准。
- 发布通过已有导出事务实现：对象、原版本和来源 metadata 一同提交。丢失提交回执时仅查询已提交结果；数据库无法确认是否提交时保留孤立字节，不误删可能已交付的文件。
