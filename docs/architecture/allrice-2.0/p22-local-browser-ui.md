# P22：本地浏览器授权与工作台

管理入口 `/workspace/local-browser` 使用当前真实会话和租户管理员权限。创建授权只登记设备、精确公网 HTTPS origin 和上传/下载/人工敏感输入范围，不启动 Chrome，不赋予员工工具，也不修改正在运行的冻结配置。设备无需选择文件工作区即可使用浏览器；命令沙箱和文件权限仍独立。

默认不保留登录资料。显式保留时，页面说明本机私有目录中的未加密登录状态及撤销后等待设备清理确认的语义，不宣称 Keychain 加密。授权错误、跨 owner 操作和公网 origin 预检失败不会落授权。撤销请求记录后主动轮询回执，设备离线时不能提前显示“已清理”。

ChatFlow 通过 canonical/native tool 事件显示共享浏览器工作台；本地和云端标题、设备名称与登录资料保留说明明确区分，不通过普通聊天文本推断工具事件。页面复用 P21 的控制 fence、观察、审批和工件，不增加第二套控制状态。
