# MET-155 PR2：开发协作流程进入冻结 Skill

日期：2026-09-27。基线：PR1 已合并的 main `d8d463c`。

## 复用与职责

开发协作继续使用 DSH 原生 Subagents 与现有 `assistant.development`、`assistant.report`、本地沙箱、候选版本账本和交付下载。不接入 Team，不涉及 MET-145 / MET-146，不新建编排或执行引擎。

新增 `development-cooperation` Skill，把 Allrice 原有编辑、测试、独立审查和交付 SOP 放入可审核的 Markdown 资源。它是 Allrice 对既有平台工具的操作说明，不冒称 DSH 原生开发协作 Skill。管理员从同一技能页选择、保存发布；依赖使用 PR1 已收敛的装配器，不再保留“添加开发协作工具”的专用按钮。

根任务按原生 Skill 机制使用说明。给助手分配开发任务时，Worker 从本次 Run 的冻结 Skill 中读取流程、相应角色和交付模板，并连同真实候选引用传给原生 Subagent。持久化后的消息用于恢复，不读取当前目录最新内容。只改 SOP 时更新资源版本和 checksum，再按既有流程发布员工，无需修改 Worker。

以下继续由程序校验，不能搬进提示词取代：JSON 参数契约、调用身份、路径占用、候选 SHA、命令回执、审查独立性、证据注册、交付就绪、审批/自动执行及任务时钟。参数错误的定向修正提示也保留在对应工具边界。

## 兼容与回退

- 已发布版本和排队任务不自动改写。只有新草稿选择本 Skill 后，才使用新资源。
- 没有本 Skill 的历史运行包沿用旧说明，单独集中在兼容函数；不是两套新流程同时维护。待旧包无需恢复时才能删除此分支。
- 已选择 Skill 但冻结资源损坏时直接报错，不静默降回旧说明。
- 成员工作设置决定自动执行或等待确认。新流程先提交真实操作，再处理实际等待，不凭空等待尚未产生的审批卡。
- 员工版本回退使用原接口，完整恢复旧冻结包；不需要数据库迁移。回退 Worker 代码不会改写已冻结资产，但将重新使用旧版内嵌助手提示，因此优先回退员工版本。

## 验证

新增 PostgreSQL 集成使用仓库真实 Skill：选择后装配工具、发布、资源单独升级、旧排队快照不变、恢复旧版本及损坏资源拒绝。Bridge 回归同时验证历史说明和冻结说明经过真实消息持久化接口后的恢复。

原有开发协作账本、候选冲突、测试/审查回执和原生 Subagents 集成继续覆盖执行机制。模型、设备和真实文件交付的 Dev 验收记录在本工单最终验收文档，不把合成测试等同于真实模型交付。

本批减少的是业务 SOP 对 Worker 发版的耦合；不会直接让模型推理更快，也没有删除仍需维护的核心账本校验。
