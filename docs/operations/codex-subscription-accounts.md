# Codex 订阅账号

后台「平台设置 → 模型与用量 → Codex 订阅」管理两份独立授权：

- 1 号 metasnowsky：沿用既有 DSH 授权目录，不移动或复制凭证。
- 2 号 encorealpha：在独立目录完成 DSH 原生设备授权。请在 OpenAI 页面登录对应账号。

授权不会自动启用。管理员可以选择一个账号或全部停用；数据库唯一索引保证最多一个启用，更新携带预期当前账号，避免多个页面覆盖彼此选择。全部停用保留两份授权，新 Codex 任务会收到明确提示。

任务尚未终结（包括排队、重试、等待审批）或员工测试正在运行时，切换和停用会返回提示。短事务锁住任务准入与账号选择，事务内不等待任务结束。请结束这些任务后再切换。正在使用且已连接的账号须先停用才能重新授权。

对话、图片和联网搜索读取同一个启用账号。原生运行时缓存包含授权目录身份，因此切换后即使两份凭证的大小和修改时间相同，也不会复用旧账号进程。账号健康状态和订阅额度分别记录；不把订阅额度转换为 Token。

凭证由 DSH 保存和刷新，不进入数据库或浏览器：

- 1 号：`ALLRICE_DSH_PLATFORM_HOME`
- 2 号：`ALLRICE_DSH_PLATFORM_HOME/codex-subscriptions/2`

账号名称是管理标签，授权时仍须核对 OpenAI 当前登录账号。平台模型、员工配置和已有会话继续使用原逻辑连接，无需重复配置。

迁移 `0121_codex_subscription_slots.sql` 保留现有 1 号授权、额度及历史授权记录；原来已紧急停用的部署会保持全部停用。启用账号的明确操作会解除旧连接的紧急停用。

验证覆盖：PostgreSQL 互斥、并发管理员更新、任务准入竞争、全部停用、两号授权及取消隔离、运行时缓存切换、桌面和移动端控件。新增账号的真实授权需要管理员亲自完成官方登录。
